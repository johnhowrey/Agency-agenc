# Etsy Relaunch Playbook — Drama Nerd Designs

> A step-by-step guide to reopening the DramaNerdDesigns Etsy shop and getting back to sales.

## Overview

The DramaNerdDesigns Etsy shop has 300+ five-star reviews and an established URL, but is currently inactive. This playbook walks through reopening strategically — not just flipping the switch, but relaunching in a way that rebuilds momentum.

## Phase 1: Preparation (1-2 Weeks Before Relaunch)

### Inventory & Product Readiness
- [ ] Confirm inventory levels for all products you plan to list
- [ ] Decide which products to launch with (see Launch Order below)
- [ ] Ensure product quality — order samples if anything has changed
- [ ] Check packaging supplies (tubes for maps, boxes for cards, etc.)
- [ ] Set up shipping workflow (printer, labels, packing materials)

### Photography
- [ ] Review existing product photos — are they still good enough?
- [ ] Shoot new photos if needed (minimum 5 per listing, aim for 10)
- [ ] Include: flat-lay, lifestyle/in-context, detail shots, scale reference, packaging
- [ ] Ensure consistent lighting and style across all products
- [ ] Create at least one "collection" photo showing multiple products together

### Listing Copy
- [ ] Write optimized titles for each listing (use Product Copywriter agent)
- [ ] Write full descriptions for each listing
- [ ] Research and select 13 tags per listing
- [ ] Choose the most specific Etsy categories for each product
- [ ] Set pricing (see Pricing Checklist below)

### Shop Settings
- [ ] Update shop announcement — acknowledge the return, build excitement
- [ ] Refresh shop banner and profile photo if needed
- [ ] Update shop policies (shipping times, returns, etc.)
- [ ] Set up shipping profiles (free shipping recommended)
- [ ] Enable Etsy Payments if not already active
- [ ] Review and update auto-reply for messages

## Important: Hiatus Timeline

**The shop will go on hiatus in mid-April 2026.** This means every day counts. The relaunch strategy is designed to maximize sales in a compressed window (now through mid-April), not build slowly over months.

Don't list everything at once. Stagger over the first few days to get multiple bumps in Etsy's algorithm (new listings get a temporary boost).

### Day 2: The Newcomer

## Phase 4: First 30 Days

### Week 2
- Run a small promotion (10% off or free shipping over $X)
- Ask first buyers to leave reviews
- Continue daily Instagram posting
- Analyze which listings get the most views vs. sales

### Week 3
- Optimize underperforming listings (new photos, adjusted titles/tags)
- Experiment with Etsy Ads on top-performing listing ($1-5/day budget)
- Create a bundle listing (Tote Bag + Oracle Cards, or Tote Bag + Mug)
- Cross-promote on other channels

### Week 4
- Full review: What's working? What needs adjustment?
- Plan Month 2 content calendar
- Set revenue goals for next month
- Consider seasonal adjustments to listings

## Pricing Checklist

For each product, verify:
- [ ] Price covers: materials + packaging + shipping + Etsy fees (6.5% transaction + 3% + $0.25 payment processing + $0.20 listing fee)
- [ ] Price includes free shipping (baked in) — Etsy's algorithm rewards this
- [ ] Price feels fair relative to competitors (check similar items on Etsy)
- [ ] Price reflects the quality and uniqueness of the product
- [ ] Consider psychological pricing ($35 vs $36 — test both)

### Etsy Fee Quick Reference
| Fee Type | Amount |
|----------|--------|
| Listing fee | $0.20 per listing (renews every 4 months or at sale) |
| Transaction fee | 6.5% of sale price + shipping |
| Payment processing | 3% + $0.25 per transaction |
| Offsite ads (if applicable) | 15% of sale (for shops under $10k/year, can be opted out) |

**Rule of thumb**: Etsy takes roughly 10-13% of each sale. Price accordingly.

## Etsy SEO Quick Wins

1. **Use all 13 tags** on every listing — don't leave any blank
2. **Title keywords matter most** — front-load with top search terms
3. **Renew strategically** — manually renewing a listing pushes it up temporarily
4. **Star Seller badge** — respond to messages within 24 hours, ship on time, maintain 5-star reviews
5. **Fill all 10 photo slots** — more photos = higher conversion AND better search ranking
6. **Update for seasons** — swap in holiday-relevant keywords in Q4

## Troubleshooting

**No views?** → Check your SEO (titles, tags, categories). Make sure you're in the right category.

**Views but no sales?** → It's usually photos or pricing. Improve main listing photo. Check competitor pricing.

**Sales but no reviews?** → Follow up with buyers (Etsy allows a polite "how was your order?" message). Include a thank-you note in the package asking for a review.

**Traffic dropping?** → Renew listings, add new products, run a promotion. Etsy rewards active shops.
